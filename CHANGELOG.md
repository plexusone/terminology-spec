## [v0.1.0] - 2026-07-26 ([`4f0b77a`](https://github.com/plexusone/terminology-spec/commit/4f0b77a))

### Highlights

- Canonical term IR for consistent handling of proper nouns, acronyms, and standard names across TTS, subtitles, and localization
- 247 embedded terms available as a Go dependency with no filesystem access

### Added

- `Term` struct with `id`, `canonicalForm`, `aliases`, `pronunciations`, `translations`, and metadata fields ([`634963c`](https://github.com/plexusone/terminology-spec/commit/634963c))
- `TranslationPolicy` enum: `preserve`, `translate`, `transliterate`, `localized-name`, `context-dependent` ([`634963c`](https://github.com/plexusone/terminology-spec/commit/634963c))
- `Builtin()` — load ~237 embedded generic-industry terms for case-correction ([`634963c`](https://github.com/plexusone/terminology-spec/commit/634963c))
- `Curated()` — load ~10 hand-authored canonical terms with real pronunciation/translation data ([`634963c`](https://github.com/plexusone/terminology-spec/commit/634963c))
- `All()` — Builtin merged with Curated (Curated wins on ID collision) ([`634963c`](https://github.com/plexusone/terminology-spec/commit/634963c))
- `LoadDir()` and `LoadFS()` for loading terms from project directories or embedded filesystems ([`634963c`](https://github.com/plexusone/terminology-spec/commit/634963c))
- `ExportPronunciationProfile()` — term → locale → spoken form for TTS providers ([`634963c`](https://github.com/plexusone/terminology-spec/commit/634963c))
- `ExportCaseDictionary()` — lowercase alias → canonical form for subtitle correction ([`634963c`](https://github.com/plexusone/terminology-spec/commit/634963c))
- `ExportTranslationMap()` — canonical form → translated form for a given locale ([`634963c`](https://github.com/plexusone/terminology-spec/commit/634963c))
- `Merge()` and `Filter()` utilities for combining and selecting terms ([`634963c`](https://github.com/plexusone/terminology-spec/commit/634963c))
- JSON schema at `schema/terminology.schema.json` generated from Go types ([`636a91c`](https://github.com/plexusone/terminology-spec/commit/636a91c))
